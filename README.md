## Books
All book-specific information lives under Books. Each title can have its own detail page and Amazon link.

## Adding books later
Open `content.js` in a text editor and add another object inside the `books` array. Add its cover image to `assets/` and paste the live Amazon URL into `amazonUrl`.

This is a static website: no Wix or Payhip account is required. Hosting/domain setup is a separate step.


Version 4 removes the three aesthetic reference photos from the homepage. They were inspiration only. The homepage now uses an original CSS visual treatment inspired by the warm, literary, cream-and-brown mood while retaining the black Delia Archer background and smooth crossfade effect.
